# OrchardCraft

OrchardCraft is a static, single-page landing site for a premium apple producer. It includes a hero section, product filtering, sustainability highlights, certifications, testimonials, and contact/newsletter forms.

## Project Files

- `index.html` - page structure
- `styles.css` - visual design and responsive layout
- `script.js` - interactivity, animations, filters, and form behavior
- `assets/` - images and other static files

## Run Locally

Open [index.html](/index.html) in a browser, or serve the folder with any static file server.

## Notes

- No build step is required.
- The contact and newsletter forms are front-end demo interactions only.
