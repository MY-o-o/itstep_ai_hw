# Детекція на потоці + ідентифікація облич (варіант Claude)

Три способи користуватися одним рушієм інференсу:

1. **Програма 1 (CLI)** — детекція об'єктів на живому відео з камери (YOLO, 80 класів COCO).
2. **Програма 2 (CLI)** — об'єкти + ідентифікація облич: розпізнає предмети (YOLO) і визначає,
   *хто* в кадрі, порівнюючи обличчя з базою фото (InsightFace / ArcFace).
3. **GUI-дашборд** — сучасний інтерфейс у стилі **Apple Human Interface Guidelines** (PySide6 +
   власна тема, світла/темна). Тулбар із сегментованим перемикачем режимів, а **інспектор
   справа змінюється залежно від режиму**:
   - *Детекція* — повзунок впевненості, фільтр «лише люди», графіки FPS / об'єктів у часі /
     об'єктів за класами, картки (FPS, об'єктів, класів, сер. впевненість, усього детекцій,
     класів за сесію) та список класів.
   - *Обличчя* — поріг впізнавання й частота розпізнавання, графіки FPS / впізнано-невідомо у часі /
     схожість за обличчями, картки (облич, впізнано, невідомих, осіб у базі, унікальних за сесію)
     та список «хто зараз у кадрі».

**Контроль порушень.** У режимі «Обличчя», якщо незнайома особа (`Unknown`) лишається в кадрі
довше за `INTRUSION_SECONDS` (1 c), застосунок робить скріншот у `data/incidents/`, а в тулборі
зростає лічильник «⚠ Порушень». Після зупинки/закриття формується звіт `data/reports/incident_report_*.md`
(час, тривалість, файл скріншота) і показується підсумкове вікно.

**Продуктивність режиму облич.** Важкі моделі (YOLO + InsightFace) рахуються раз на `FACE_EVERY`
кадрів із кешуванням рамок між ними, менший `FACE_DET_SIZE` і `YOLO_IMGSZ`, буфер камери = 1 —
кадри показуються щоразу, тож FPS вищий. Частоту можна крутити повзунком прямо в інтерфейсі.

## Структура

```
detection_face_id_claude/
  config.py                      # дефолти: камера, пороги, шляхи
  common/                        # утиліти: камера, малювання
  engine/                        # спільне ядро інференсу (для CLI та GUI)
    detector.py                  #   ObjectDetector (YOLO)
    face_identifier.py           #   FaceIdentifier (InsightFace ArcFace)
  program1_detection/detect_stream.py
  program2_face_id/enroll.py     # будує базу облич з data/photos/
  program2_face_id/identify_stream.py
  gui/                           # дашборд у стилі Apple HIG
    app.py                       #   точка входу GUI
    theme.py                     #   тема HIG (світла/темна), кольори, шрифт SF
    worker.py                    #   фоновий потік інференсу (QThread)
    main_window.py               #   тулбар + відео + інспектор (QStackedWidget)
    panels.py                    #   DetectionPanel / FacePanel — контроли й графіки по режиму
    widgets.py                   #   Card, StatCard, SegmentedControl
  data/photos/<ім'я>/*.jpg        # вхідні фото для бази
  data/db/face_db.npz            # згенерована база (після enroll.py)
```

## Встановлення

Потрібен **Python 3.11** (для CV/ML-бібліотек ще немає колес під 3.14).

```bash
cd detection_face_id_claude
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> Перший запуск автоматично завантажить ваги YOLO (`yolo11n.pt`) та модель-пак InsightFace
> `buffalo_l` (у `~/.insightface`). Потрібен інтернет на першому старті.

## Запуск

**Програма 1 — детекція об'єктів:**
```bash
python program1_detection/detect_stream.py --camera 0
# лише люди:        --classes 0
# інша камера:      --camera 1
```

**Програма 2 — ідентифікація облич:**
```bash
# 1) Покласти 2–5 фото кожної людини у data/photos/<ім'я>/
# 2) Побудувати базу:
python program2_face_id/enroll.py
# 3) Запустити ідентифікацію на потоці:
python program2_face_id/identify_stream.py --camera 0
```

Клавіші у вікнах: `q` — вихід, `s` — скріншот (Програма 1).

**GUI-дашборд (обидва режими + графіки):**
```bash
python gui/app.py
```
У вікні: у тулборі — сегментований перемикач *Детекція / Обличчя*, вибір камери, перемикач
теми (Темна/Світла), кнопки **Знімок** і **Старт**. Праворуч інспектор автоматично показує
інструменти, графіки та метрики саме обраного режиму. Режим «Обличчя» потребує бази
(спочатку `enroll.py`).

## Корисні параметри

| Параметр | Де | Призначення |
|---|---|---|
| `--camera N` | обидві | індекс камери (перебрати 0,1,2… якщо не та) |
| `--conf 0.4` | обидві | поріг впевненості детекції об'єктів |
| `--classes 0 67` | прог. 1 | фільтр класів COCO за id |
| `--threshold 0.35` | прог. 2 | поріг косинусної схожості облич |
| `--every 3` | прог. 2 | розпізнавати обличчя кожні N кадрів (плавніше) |

## Нюанси (macOS)

- **Дозвіл на камеру:** дайте доступ терміналу/IDE у *System Settings → Privacy & Security →
  Camera*, інакше кадри будуть порожні.
- **Кілька камер** (FaceTime HD, OBS, Sony, EOS): якщо `--camera 0` не та, перебрати індекси
  або виконати `python common/camera.py` — виведе доступні.
- **Поріг облич** (`FACE_THRESHOLD`, ArcFace-косинус ~0.3–0.5): нижче → більше «Unknown»;
  вище → ризик хибних збігів.
